# GitHubWatcher

Monitor GitHub repositories in a Discord server.
Generated by ChatGPT.
Go away, non-AI guy!

## Setup

1. Fill in the `config.json` file (`./config.json`) with your bot data and the Discord server **category ID**.

   > The category ID is used to create the generated channel.
   > [How to get it](https://letmegooglethat.com/?q=How+to+get+Discord+server+category+ID)

2. Open the [Discord Developer Portal](https://discord.com/developers/applications) and select your application (or create a new one).

3. Go to **OAuth2** in the sidebar and scroll down to **OAuth2 URL Generator**.

4. Under **Scopes**, select:

   * `applications.commands`
   * `bot`

5. Under **Bot Permissions**, select:

   * Manage Channels
   * View Channels
   * Send Messages
   * Manage Messages
   * Pin Messages
   * Embed Links
   * Read Message History
   * Use Slash Commands

6. Use the generated URL to invite the bot to your desired server.

7. Deploy the slash commands (don’t skip this or your bot will just sit there looking dumb):

   ```bash
   node deploy-commands.js
   ```

8. Finally, run the bot (this is where the magic actually happens):

   ```bash
   node index.js
   ```

## Commands

* `/watchrepo repo_link`
